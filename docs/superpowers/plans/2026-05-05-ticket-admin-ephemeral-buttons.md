# 2026-05-05 票口管理按鈕可見性調整

## 背景

票口歡迎訊息原本直接附上關閉、認領、鎖定、發送紀錄、成員管理與重新命名等管理按鈕。Discord 的 message components 沒有單一訊息內依成員或角色隱藏部分按鈕的權限欄位，因此客人只要看得到該票口訊息，就會看得到同一則訊息上的按鈕。

## 實作

- 新票口建立後，公開歡迎訊息不再附加管理按鈕。
- 新增 `/ticket-admin` 指令，需在票口頻道內使用。
- `/ticket-admin` 會驗證使用者是否具備 Discord Administrator 權限或票口設定中的支援角色。
- 通過驗證後，以 ephemeral 回覆顯示管理按鈕，因此只有執行指令的管理員或支援人員看得到。
- 關閉票口時，公開關閉通知不再附加重新開啟、刪除、存檔等管理按鈕；管理人員可再次使用 `/ticket-admin` 取得關閉狀態的管理面板。
- `deploy-commands.mjs` 已加入 `/ticket-admin`，啟動時的自動指令部署也會註冊此指令。

## 風險與維運

- Discord 不支援把同一則公開訊息上的按鈕只顯示給特定角色；本次採用官方支援的 ephemeral interaction 回覆作為可見性邊界。
- 既有票口中已發出的舊公開管理按鈕不會自動消失；新票口與後續關閉通知會套用新行為。
- 票口支援角色權限仍由 `TicketConfig.supportRoleIds` 控制。

## 驗證

- 執行 `npm run build`。
