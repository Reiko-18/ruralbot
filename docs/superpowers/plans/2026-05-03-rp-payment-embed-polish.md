# 2026-05-03 RP 繳費訊息版面美化

## 背景

`/rp` 互動式超商繳費原始訊息使用較大的 Markdown 標題、分隔線與多色按鈕。使用者偏好淡紫色系，希望整體版面更乾淨、按鈕色系一致。

## 調整內容

- `/rp` 初始繳費單改為淡紫色 embed，使用欄位呈現繳費金額、有效時間與備註。
- 全家與 7-11 選擇按鈕統一使用 Discord `Primary` 樣式，視覺上接近紫藍色系。
- 確認付款、取號中、取號結果、取消訊息皆改為同一個淡紫色 embed 色彩。
- 確認頁與繳費結果頁改用欄位排版，減少大字標題與長分隔線。
- 取消按鈕保留 `Secondary` 樣式，避免與主要取號動作混淆；Discord 不支援任意自訂淡紫按鈕色。

## 驗證

- `npm run build`：通過。
