# 2026-05-03 RP 繳費訊息版面美化

## 背景

`/rp` 互動式超商繳費原始訊息使用較大的 Markdown 標題、分隔線與多色按鈕。使用者偏好淡紫色系，希望整體版面更乾淨、按鈕色系一致。

## 調整內容

- 2026-05-04 追加：新增 Discord 自訂 emoji 解析工具，金流訊息可使用 bot 已加入伺服器中可用的自訂 emoji，包含動態 emoji。
- 2026-05-04 追加：金流版面指定使用 `<a:ZSz26520125622:1343576083617812502>`，若 cache 中可解析就以 guild emoji 物件渲染，否則保留原始 Discord emoji 格式。
- 2026-05-04 追加：超商選擇與付款完成訊息改用專用 emoji，包含全家 `<:FamilyMart:1332695203735142440>` 與 7-11 `<:711:1332695189403336738>`。
- 2026-05-04 追加：`/rp` 初始頁、付款方式確認頁、購買人資訊確認頁、取號結果、DM 與 callback 成功通知改用「◆ / ◇ / └」符號裝飾，貼近 Discord 內嵌訊息範例風格。
- 2026-05-04 追加：取號成功訊息將「繳費位置」與「繳費代碼」提升到描述區醒目呈現；使用者可見的訂單編號改為短碼，完整 `PAY-...` 仍保留於資料庫與 SmilePay callback 對帳流程。
- `/rp` 初始繳費單改為淡紫色 embed，使用欄位呈現繳費金額、有效時間與備註。
- 全家與 7-11 選擇按鈕統一使用 Discord `Primary` 樣式，視覺上接近紫藍色系。
- 付款方式確認頁參考示例改為「再次確認您的付款方式」，顯示付款金額、手續費與下一步按鈕。
- 新增購買人資訊確認頁，未填資料時顯示「尚未填寫」，按「填寫/修改資訊」開啟 modal，填完後才可按「確認並獲取付款碼」。
- 取號中、取消訊息皆改為淡紫色 embed；成功繳費單使用綠色側邊條標示成功狀態。
- 確認頁與繳費結果頁改用欄位排版，減少大字標題與長分隔線。
- 取消按鈕保留 `Secondary` 樣式，避免與主要取號動作混淆；Discord 不支援任意自訂淡紫按鈕色。
